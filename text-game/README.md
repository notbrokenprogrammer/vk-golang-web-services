# Текстовая игра

Домашнее задание к первой лекции курса VK «Разработка веб-сервисов на Golang».

Небольшая игра с текстовым интерфейсом: игрок перемещается между комнатами, собирает предметы и взаимодействует с окружением. Чтобы выйти из дома, нужно найти рюкзак и ключи, а затем открыть дверь.

## Условие

Нужно реализовать игровой мир с комнатами и игроком. У каждого объекта есть состояние: игрок находится в определённой комнате и хранит предметы в инвентаре; комнаты содержат предметы и доступные переходы.

Программа принимает текстовые команды и возвращает ответ, который зависит от текущего состояния мира. Выполненные действия должны менять это состояние: взятый предмет исчезает из комнаты, надетый рюкзак позволяет собирать вещи, открытая дверь позволяет выйти на улицу.

Две основные функции:

- `initGame()` создаёт мир и игрока, сбрасывая состояние перед новой игрой.
- `handleCommand(command string) string` разбирает команду, выполняет действие и возвращает текстовый ответ.

Формат ввода:

```text
команда параметр1 параметр2 ...
```

### Требования задания

- Использовать только стандартную библиотеку Go.
- Моделировать комнаты, игрока и взаимодействия с помощью структур, методов и функций.
- Предусмотреть расширение мира: добавление комнат, предметов и переходов через изменение инициализации, а не отдельные реализации команд для каждого нового объекта.
- Сохранять состояние между командами и корректно обрабатывать недоступные действия.
- Не использовать таблицу готовых ответов на полные команды пользователя.
- Сохранить исходные тесты `main_test.go` без изменений.

Это краткое изложение условия. [Шаблон и локальные тесты задания](https://gitlab.com/vk-golang/lectures/-/tree/master/01_intro/99_hw) находятся в репозитории курса.

## Команды

| Команда | Действие | Пример |
| --- | --- | --- |
| `осмотреться` | Осмотреть текущую комнату | `осмотреться` |
| `идти <направление>` | Перейти по доступному пути | `идти коридор` |
| `надеть <предмет>` | Надеть рюкзак | `надеть рюкзак` |
| `взять <предмет>` | Положить предмет в инвентарь | `взять ключи` |
| `применить <предмет> <объект>` | Использовать предмет из инвентаря | `применить ключи дверь` |

## Реализация

- `Student` хранит инвентарь, состояние рюкзака и текущую комнату игрока.
- `Rooms` описывает название комнаты, предметы и доступные направления.
- `initGame()` создаёт кухню, комнату, коридор и улицу, а также задаёт начальное состояние игрока.
- `handleCommand()` разбирает ввод через `strings.Fields`, проверяет возможность действия и обновляет состояние. В текущей версии обработчики содержат условия для конкретных комнат и предметов.
- При описании предметов используется сортировка, чтобы порядок вывода был стабильным.
- `main()` читает команды построчно через `bufio.Scanner` и выводит ответы игры.

## Запуск

Из корня репозитория:

```bash
cd text-game
go run .
```

После запуска вводите команды по одной строке. Например, последовательность для выхода на улицу:

```text
осмотреться
идти коридор
идти комната
надеть рюкзак
взять ключи
взять конспекты
идти коридор
применить ключи дверь
идти улица
```

## Тесты

Из папки `text-game`:

```bash
go test -v
```

В `main_test.go` находится исходный тест курса `TestGame0`: два сценария и 35 проверяемых шагов. Они проверяют перемещение, сбор предметов, изменение описаний комнат, взаимодействие с дверью и ответы на недоступные действия.

По условию курса локальные и проверочные тесты на платформе различаются. Локальная проверка не заменяет проверку решения на платформе.
