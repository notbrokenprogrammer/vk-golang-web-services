# Разработка веб-сервисов на Go

Мои решения домашних заданий курса VK «Разработка веб-сервисов на Golang».

Каждая работа находится в отдельной папке. В ней собраны исходный код, локальные тесты и README с условием, описанием реализации и командами запуска.

## Запуск и проверка

Для работы нужен установленный Go. Каждое задание — самостоятельный Go-модуль; команды выполняются из его папки.

Например, запуск текстовой игры:

```bash
cd text-game
go run .
```

Проверка тестов из той же папки:

```bash
go test -v
```
